# php-basics-practice

## 概要

COACHTECH 教材 Tutorial 7-1-6「PHPの基礎 ハンズオン演習」で作成した成果物です。 このページの内容は、変数に代入されている値から商品の価格を求めて出力します。

## 使用技術

- PHP 8.2
- Docker

## 学んだこと

- PHP内でもechoを通じてHTMLのタグを利用できること
- PHPでの変数やechoや演算子の扱い方を実践を通して学べた

## 動作確認

コンテナを起動して、
http://localhost:8000/7-1-6_hands-on/practice/price_calculator.php にアクセス。
